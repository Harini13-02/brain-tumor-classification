# Brain Tumor Classification and Risk Prediction Using Data Mining and Machine Learning

An end-to-end, full-stack educational research web application designed to evaluate cranial MRI images across deep learning and traditional machine learning estimators, and visualize exploratory data mining insights (PCA, K-Means clustering, and Apriori association rules).

---

## ⚠️ Important Medical Safety & Educational Notice

> **RESEARCH NOTICE:** This application is an educational research prototype. Its predictions are generated by machine learning models and are **not a medical diagnosis**. Model confidence represents uncalibrated statistical output, not clinical certainty or patient risk. Consult a qualified healthcare professional for clinical interpretation and medical decisions.

---

## 🌟 Key Features

1. **Multi-Model Inference Pipeline:**
   - **Random Forest Classifier (Default):** 92.45% recorded test accuracy using 128-dimensional dense CNN feature embeddings.
   - **Decision Tree Classifier:** 89.86% recorded test accuracy.
   - **K-Nearest Neighbors (KNN):** 89.70% recorded test accuracy with automated `StandardScaler` pipeline.
   - **Support Vector Machine (SVM):** 86.42% recorded test accuracy with RBF kernel and `StandardScaler` pipeline.
   - **End-to-End Convolutional Neural Network (CNN):** 77.80% recorded test accuracy.
2. **Four Target Tumor Classes:**
   - `glioma`
   - `meningioma`
   - `notumor`
   - `pituitary`
3. **Medical Safety UI Guardrails:**
   - Titled **MRI Classification Result** (never "confirmed diagnosis").
   - Explicit disclaimers on notumor predictions explaining lack of clinical diagnostic guarantees.
   - Strictly no fabricated risk scores, tumor staging, prognosis, or surgical/drug recommendations.
4. **Data Mining & Evaluation Analytics Dashboard:**
   - **Model Comparison:** Accuracy, Precision, Recall, and F1-score across all 5 models.
   - **Confusion Matrix & Classification Report:** Per-class support, precision, and recall.
   - **Principal Component Analysis (PCA):** 2D projection of 128-d features explaining 43.26% of feature variance.
   - **K-Means Clustering:** Unsupervised k=4 clustering with recorded Adjusted Rand Index of 0.6248.
   - **Apriori Association Rules:** Discovered frequent itemsets and rules with support, confidence, and lift.
5. **Secure Authentication & Session History:**
   - User registration and login powered by secure **Bcrypt** password hashing.
   - Stateless **JWT (JSON Web Tokens)** authorization.
   - User-isolated prediction history stored in **SQLite** with pagination, filters, search, and deletion.
   - Automated **PDF Report Generation** with ReportLab.

## 🛠️ Technology Stack

- **Frontend:** React 18, Vite, JavaScript, Tailwind CSS, React Router v6, Recharts, Lucide React.
- **Backend:** Python FastAPI, Uvicorn, Pydantic v2.

## 🚀 Setup & Execution Guide (Windows / VS Code)

Open **two separate terminal windows** in VS Code (Terminal 1 for Backend, Terminal 2 for Frontend).

### Terminal 1: Backend Setup & Execution (FastAPI)

1. Open PowerShell and navigate to the backend folder:
   ```powershell
   cd "D:\TUMOR DATA MINING PROJECT\backend"
   ```

2. (Optional) Create and activate a Python virtual environment:
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

3. Install required Python packages:
   ```powershell
   pip install -r requirements.txt
   ```

4. Verify your environment file:
   - Ensure `backend/.env` exists (copied from `.env.example`).
   - Default port is `8000`.

5. Start the FastAPI server:
   ```powershell
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
   ```

6. Verify backend is running:
   - Health check: [http://127.0.0.1:8000/api/health](http://127.0.0.1:8000/api/health)
   - Interactive Swagger API docs: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

---

### Terminal 2: Frontend Setup & Execution (Vite + React)

1. Open a second PowerShell terminal and navigate to the frontend folder:
   ```powershell
   cd "D:\TUMOR DATA MINING PROJECT\frontend"
   ```

2. Install npm dependencies:
   ```powershell
   npm install
   ```

3. Start the Vite development server:
   ```powershell
   npm run dev
   ```

4. Open your browser and navigate to:
   - [http://localhost:5173](http://localhost:5173)

## 🔧 Troubleshooting

| Issue | Cause & Solution |
| :--- | :--- |
| **Model loading error** | Verify `models/` folder path. The backend auto-locates `../models` and `models/`. Check with `GET /api/health`. |
| **CORS errors** | Ensure frontend runs on `http://localhost:5173`. Check `CORS_ORIGINS` in `backend/.env`. |
| **Port already in use** | If port 8000 is occupied, set `PORT=8001` in `.env` and start uvicorn on `--port 8001`. In frontend, set `VITE_API_URL=http://localhost:8001` in `.env`. |
| **PowerShell script execution disabled** | If `Activate.ps1` fails, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` in your PowerShell window. |
| **SQLite database lock** | SQLite database file `brain_tumor_app.db` is configured with `check_same_thread=False` for concurrent worker queries. |
